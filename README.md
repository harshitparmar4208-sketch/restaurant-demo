# Maison Café — GitHub Pages Demo

A responsive digital restaurant menu demo with:
- Menu categories
- Add-to-cart functionality
- Demo checkout
- Mobile-friendly design
- No external libraries required

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a public GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → /(root)

The generated Pages URL will look like:
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
